# Data-Driven Deep Learning Approach for Early Detection of Acute Lymphoblastic Leukemia

## Project Overview
This is a team project that uses Deep Learning to support the early detection of Acute Lymphoblastic Leukemia (ALL) from blood cell images. The project integrates a Convolutional Neural Network (CNN) with a Django web application to classify medical images and provide prediction results through a user-friendly interface.

## Technologies Used
- Python
- Django
- TensorFlow / Keras
- OpenCV
- NumPy
- Pandas
- HTML
- CSS
- SQLite

## Features
- Blood cell image classification
- Deep learning-based prediction
- User authentication
- Simple web interface
- Fast and accurate prediction results
